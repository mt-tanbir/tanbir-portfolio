# Tanbir Mahmud Portfolio

A single-page React portfolio presenting Tanbir Mahmud's profile, skills, projects, work experience, and contact information.

## Requirements

- Node.js and npm

## Run locally

```sh
npm install
npm start
```

The development server runs at [http://localhost:3000](http://localhost:3000).

## Production build

```sh
npm run build
```

The optimized static site is written to `build/` and can be deployed to a static hosting service.

## Updating portfolio content

- Profile and resume: `src/data/profile.js`
- Contact details and social links: `src/data/contact.js`
- Skills, projects, and experience: corresponding files in `src/data/`
- Page title and social sharing metadata: `public/index.html`

Project demo links are maintained in `src/data/projects.js`. The featured project descriptions and technology lists are based on Tanbir's current CV.
